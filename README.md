# station2-kit

Spotify (Soloist), голос Алисы в Spotify, VPN и веб-панель для **уже взломанной** Яндекс Станции 2.

Это не прошивка колонки и не способ получить root. Основы доступа к станции (root, SSH, отключение облачных обновлений Яндекса) взяты из открытой вики **[Yandex Station Extended](https://hackalice.me/)** и чата [@hackalice](https://t.me/hackalice). Без этого кит не ставится.

Ключи Spotify, VPN и приватный SSH в репозиторий **не входят**.

## Два разных действия

| | Когда | Что качать | Что происходит |
|---|---|---|---|
| **Установка** | колонка ещё без Soloist | `station-kit.zip` из [Releases](https://github.com/Jidos86/station2-kit/releases) | на колонку копируются Soloist, Xray, Luna, AP2, скрипты |
| **Обновление** | кит уже стоит | ничего вручную | панель качает маленькое `station-core.tar`: скрипты, голос, громкость, веб. Бинарники заново не кладутся — на `/data` нет места |

Панель смотрит манифест:

https://github.com/Jidos86/station2-kit/releases/latest/download/station-version.json

## Установка (полная)

Нужны: Станция 2 с **root и SSH на порту 2222** (как в [hackalice.me](https://hackalice.me/)), компьютер на Windows, **Spotify Premium**, одна Wi‑Fi с колонкой.

1. Скачайте **`station-kit.zip`** с [последнего релиза, где есть этот файл](https://github.com/Jidos86/station2-kit/releases) (если в latest его нет — возьмите из предыдущего релиза).
2. Распакуйте так, чтобы сразу были видны `install.cmd`, `ap2`, `soloist`, `xray`, `boot`. Если внутри ещё одна папка `station-kit` — работайте с внутренней.
3. Ключ Soloist: [developer.spotify.com/dashboard/soloist](https://developer.spotify.com/dashboard/soloist) (это не пароль аккаунта и не Client ID).
4. Для поиска голосом заранее создайте приложение Web API: [Dashboard](https://developer.spotify.com/dashboard) → Create app → Redirect URI строго `http://127.0.0.1:5589/callback` → скопируйте **Client ID**.
5. Запустите `install.cmd`. IP колонки, затем ключ Soloist (символы не видны). Если кит уже ставили — оба ключа можно не вводить, **Enter**.
6. Если спросят SSH-пароль колонки — введите его.
7. Дождитесь строки «Готово».
8. В Spotify на телефоне (та же Wi‑Fi) выберите устройство **«Станция 2 Soloist»**.
9. Голосом: «Алиса, поставь …», «включи песню …», «поставь альбом …», «пауза», «дальше».
10. Панель: `http://IP/` (Spotify + VPN). Luna: `http://IP:8099`.

Поиск голосом можно добить позже: `login-spotify.cmd` в той же папке. Для входа с панели на компьютере нужен Redirect на `127.0.0.1` — либо `oauth-catch.cmd`, либо после «Принимаю» скопировать адрес с `code=` и нажать «Готово».

Погода, таймеры и умный дом Алисы остаются как были.

## Обновление (уже стоит)

1. Откройте `http://IP/` с телефона или компьютера в той же сети.
2. Проверка обновлений → поставить.
3. Качается только ядро скриптов. Полный Soloist/Xray повторно не скачивается.

Если на панели `invalid tar magic` или `No space left on device` — не жмите повтор на старом битом архиве: удалите `/data/local/opt/station/var/*.tar` (или напишите автору кита) и ставьте релиз, где ядро — обычный маленький tar.

## Что в релизах

- `station-kit.zip` — полная установка с Windows-установщиком.
- `station-core.tar` — ядро для панели (скрипты и обвязка, без второго комплекта тяжёлых бинарников).
- `station-version.json` — версия и sha256 ядра.
- `catalog.json` — каталог модулей панели.

В архивы не кладутся: Soloist API key, Spotify OAuth, URL подписки VPN, приватный ключ dropbear.

## Лицензии и происхождение

Доступ к Станции 2, SSH и идея жить со своим софтом на колонке — экосистема **[hackalice.me](https://hackalice.me/)** (Yandex Station Extended). Этот репозиторий — отдельный слой: Spotify Connect через Soloist, голосовой поиск, синхрон громкости и панель VPN.

Только свои устройства. Ключи и токены никуда не выкладывайте.
